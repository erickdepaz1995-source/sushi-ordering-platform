# Product Requirements Document (PRD)

## Problem Statement

Muchos restaurantes de sushi pequeños y medianos gestionan sus pedidos mediante WhatsApp, llamadas telefónicas o plataformas de terceros que cobran comisiones y ofrecen poca flexibilidad para personalizar la experiencia del negocio. Además, desarrollar una aplicación propia suele representar un costo elevado para este tipo de restaurantes.

Existe la necesidad de una plataforma de pedidos en línea bajo un modelo de suscripción que permita a múltiples restaurantes administrar su propio menú, recibir pedidos y gestionar su operación desde un mismo sistema, reduciendo costos y facilitando la digitalización de sus negocios.
